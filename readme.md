# Desafio JusBrasil - Pipeline PNL

Aplicação em Python executada via container Docker para processamento de linguagem natural (PNL) e aprendizado de máquina supervisionado.

**Tecnologias Utilizadas**
* Python 3.11
* Docker
* Git / GitHub

**Como Executar o Projeto**

1. Certifique-se de que o Docker Desktop está em execução.
2. Compile a imagem Docker no terminal:
   docker build -t desafio-jusbrasil .

3. Execute o container:
   docker run desafio-jusbrasil
